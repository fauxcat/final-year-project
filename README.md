# UP2107490's Project

A personal fitness and diet tracking application for UP2107490's Final Year Engineering Project.

ALL files relevant to this project/written by UP2107490 are located in the "lib" folder. 

Excluding Hive-generated files (e.g. xxxxxx.g.dart), all files in the "lib" folder were written by UP2107490.

## Prerequisites

Please ensure you have the Flutter SDK along with the Flutter and Dart extensions in VS Code installed.

## Getting Started

1. Run "flutter pub get" in the terminal

2. Navigate to lib/main.dart and run the application with a device of your choice.
